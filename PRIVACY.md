# Privacy Policy for Antenna: Local AI Desktop Companion

**Effective Date:** November 20, 2026  
**Publisher:** Floyogen

## 1. No Personal Data Collection
**Antenna: Local AI Desktop Companion** is a 100% offline Windows desktop application. Floyogen does not collect, store, track, sell, or transmit any personal information, chat logs, usage analytics, or telemetry to any external servers.

## 2. Local AI Processing
Antenna communicates exclusively with user-configured local Large Language Model (LLM) servers running on the user's own machine (such as Ollama or LM Studio on `localhost`). All prompts and AI responses remain strictly on your local hardware.

## 3. Native Windows Features
Antenna uses native Windows Text-to-Speech (TTS) and optional user-permitted application launching. These actions are executed locally on your device and are never logged or shared externally.

## 4. Local Settings Storage
User preferences (such as selected model name, voice settings, and UI toggles) are stored locally on your PC and can be cleared at any time by uninstalling the application.
