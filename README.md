Antenna: Local AI Desktop Companion (V1.0.0)
Meet Antenna (Ania Meyyar), a hand-drawn desktop companion from Sector 6 of Talloon City in the MPheno universe, created by FLOYOGEN.

She lives on your Windows desktop, where you can chat with her, hear her speak, and ask her to open applications on your PC. Antenna works with locally running AI models, so your conversations don't need to go through a cloud-based AI service.
Features
- Desktop Overlay: Antenna stays on top of your workspace without the usual window borders. You can interact with your desktop while she hangs around.
- Local AI Support: Connect models through Ollama or LM Studio, including Gemma, Llama, Qwen, Mistral, and other compatible models.
- Windows Voice & Lip-Sync: Use voices already installed on your PC, adjust speech speed and volume, and watch Antenna's sprites respond as she speaks.
- Application Launching: Ask Antenna to open installed Windows applications. You can control this feature through a dedicated permission setting.
- Idle Mode: After five seconds of inactivity, the floating interface fades away, leaving Ania visible on your desktop.
- Hand-Drawn Artwork: All character sprites and expressions are drawn by hand in Krita. The interface and visual design are original FLOYOGEN work.
Getting Started
1. Download Antenna_v1.0.0_Win64.zip from the Releases tab.
2. Make sure Ollama or LM Studio is running on your PC. For example, you can start a model using ollama run gemma4.
3. Extract the downloaded ZIP file and launch Antenna.exe.
4. Open Settings (⋮) → Model and enter your provider, endpoint, and model name.
A note about Windows SmartScreen:

Since Antenna is a new indie application, Windows may display a security warning when you launch it for the first time. Make sure you downloaded it from the official release source and verify the application before deciding whether to run it.
